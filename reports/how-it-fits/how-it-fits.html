2. The map: how they can talk to each other

Think of a company. Someone decides the work (manager), people do it (workers), they use shared reference material (library) and specialist services (specialists), someone reviews (reviewers), and results show on screens (UI). The wires are three plain standards: MCP tool calls, HTTP APIs, and CLI processes, plus Git/PRs for code.

3. Where omni-agent fits

One sentence: every tool above can claim a result; omni-agent proves it, checking with something the worker can't edit, comparing the claim with reality, adding the cost, and handing you a receipt to approve in seconds.

4. Example: a team using MiroFish

A product team asks Hermes: "How will our users react if we raise the price 20%?" Hermes calls MiroFish's API. MiroFish builds a graph from the pricing doc, runs a simulated crowd of AI personas on a fake social network, and writes a report: "68% negative, churn risk high among small teams."

The problem: our MiroFish source read found no validation, backtesting or accuracy measurement anywhere in the repo; one stochastic run is narrated by an LLM. The team can't tell if "68%" means anything, and nobody checks later whether it came true.

The same pattern with Peec AI: Peec recommends "get reviews on G2, join r/CRM discussions"; an agent claims it did. omni-agent checks that the G2 profile and posts really exist (read-back), records the cost, and 30 days later reads Peec's visibility numbers through its MCP to show whether the work moved the metric: cost per verified outcome, not "the agent was busy".

License note: MiroFish is AGPL, so omni-agent only calls its HTTP API as a separate, unmodified service. No MiroFish code is copied in.

Honest reading: the pieces exist, scattered. Odysseus has the best "done" gate, but only for its own agent and under AGPL (so we take the idea, not the code). zeroshot does cross-vendor checks, but only for code and only with AI reviewers. Devin proves its own work. Nobody combines any agent + any kind of work + evidence the worker can't touch + cost + a track record over time. That combination is where omni-agent fits.
